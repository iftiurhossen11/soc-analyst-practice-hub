# Lab Deliverables

After running the analyzer, complete these files:

- `analysis-summary.md`
- `unique_ips.txt`
- `suspicious_ips.txt`
- `not-found-urls.txt`
- `LOG-ANALYSIS-REPORT.md` based on the report template

These are generated local artifacts. The published `analysis-output-example.md` is a text capture from the analyzer using only the repository's synthetic data. Review and anonymize any additional output before publishing. Do not commit real logs or unredacted evidence.
