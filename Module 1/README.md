# Module 1 — Windows Security Log Analysis

**Level:** beginner to intermediate

This module contains the complete guided labs:

- [Lab 1 — Windows Security Log Analysis](Lab 1 — Windows Security Log Analysis/README.md): PowerShell event-log queries, named XML fields, synthetic data, offline analysis, and an incident-report exercise.
- [Lab 2 — Log Analysis with CLI Tools](Lab 2 — Log Analysis with CLI Tools/README.md): Apache Combined Log Format, Bash command-line analysis, suspicious-request review, and report writing.

Lab 1 also contains the earlier network, phishing, incident-response, detection-engineering, threat-intelligence, and capstone practice under [`supporting-labs`](Lab 1 — Windows Security Log Analysis/supporting-labs/).
