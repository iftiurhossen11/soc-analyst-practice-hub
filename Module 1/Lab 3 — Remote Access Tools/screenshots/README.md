# Screenshot Evidence Guide

The supplied source PDF contains screenshots with personal and machine-identifying information. It is retained locally and excluded from Git; its images are not copied into this folder.

If you capture screenshots during your own authorized rerun:

- Use only the isolated host-only lab VM and a dedicated lab account.
- Redact usernames, profile paths, hostnames, VM addresses, notifications, and unrelated windows before publishing.
- Never show passwords, private keys, tokens, or saved credentials.
- Show only the harmless test file and sanitized client status; do not capture real logs or customer data.
- Confirm each image is safe to publish before adding it to this folder.

No screenshots are included until sanitized evidence from a new lab run is available.
