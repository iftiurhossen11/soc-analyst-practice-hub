# Lab Deliverables

After repeating the lab, complete [`../reports/REMOTE-ACCESS-TOOLS-REPORT-TEMPLATE.md`](../reports/REMOTE-ACCESS-TOOLS-REPORT-TEMPLATE.md) and retain only sanitized evidence that you are authorized to publish.

Record:

- The isolated host-only setup and SSH service state.
- The SSH host-key fingerprint verification result (never a private key).
- Which clients connected and which protocol/interface each used.
- The SHA-256 hashes of the harmless test file on the host and VM.
- Cleanup results for the test file, saved client sessions, and SSH service.

Use [`../data/remote-access-test.txt`](../data/remote-access-test.txt) as the transfer source and leave the repository copy unchanged. Delete only the temporary host/VM transfer copies during cleanup.

Do not add passwords, private keys, real usernames, hostnames, IP addresses, profile paths, production logs, or customer data. The [sanitized completion report](../reports/LAB-3-COMPLETION-REPORT.md) summarizes the supplied source report and is not generated evidence from a new run.
