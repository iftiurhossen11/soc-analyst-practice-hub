# Lab 1 — Case Timeline

**Module:** 5 · **Level:** intermediate · **Estimated time:** 1–2 hours

Build a UTC-normalized timeline from the supplied synthetic case records. Separate observed facts from interpretations and unknowns.

## Contents

- [`data/case-events.csv`](data/case-events.csv)
- [`REPORT-TEMPLATE.md`](REPORT-TEMPLATE.md)

## Tasks

1. Order the records by timestamp.
2. Correlate only fields that support the relationship.
3. Write an executive summary with confidence and alternative explanations.
4. Recommend evidence preservation and owner-approved containment options.

Do not modify, isolate, disable, or delete any real account or system.
