# Lab 1 — Static Email Triage

**Module:** 4 · **Level:** beginner · **Estimated time:** 1–2 hours

Review the fictional message in [`data/sample-email.eml`](data/sample-email.eml) as text only. Do not click its links or execute attachments.

## Tasks

1. Compare `From`, `Reply-To`, and `Return-Path`.
2. Record the displayed URL host without visiting it.
3. Identify urgency and credential-request language.
4. Record indicators, uncertainty, a user-safe disposition, and requested gateway evidence.

## Safety

Use an approved isolated environment for any future attachment analysis. This lab requires no network access.
