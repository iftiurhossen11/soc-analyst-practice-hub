# Lab 1 — Network Connection Review

**Module:** 3 · **Level:** beginner to intermediate · **Estimated time:** 1–2 hours

Review synthetic Zeek-style connection records and produce a time-bounded baseline. The addresses are documentation-only examples.

## Contents

- [`data/conn.log`](data/conn.log) — synthetic connection records
- [`REPORT-TEMPLATE.md`](REPORT-TEMPLATE.md) — timeline and assessment template

## Tasks

1. Group connections by source, destination, port, and state.
2. Explain what `S0` and `SF` establish and do not establish.
3. Propose two benign explanations for repeated short connections.
4. List the DNS, proxy, endpoint, and identity evidence needed next.

Do not scan or connect to any listed address.
