# Module 08 — Capstone Investigation

**Level:** intermediate · **Estimated time:** 3–4 hours

## Scenario

The complete capstone lab is in [labs/01-end-to-end-investigation](labs/01-end-to-end-investigation/README.md).

A fictional team reports unusual sign-in activity on a training workstation. You have the synthetic Windows events from Module 1, the network observations from Module 3, and the sample email from Module 4. There is no confirmed incident.

## Objectives

- Form and test a defensible hypothesis.
- Correlate identity, endpoint, and network evidence while noting gaps.
- Communicate severity and confidence without overstating attribution.
- Recommend reversible, owner-approved next steps.

## Deliverables

1. One-page executive summary.
2. UTC timeline with sources and confidence.
3. Queries or analysis steps sufficient for another analyst to reproduce.
4. Findings table: observation, interpretation, alternative explanation, confidence.
5. Recommended evidence collection and containment decision, including who must approve it.
6. Lessons learned and one detection improvement.

## Evaluation rubric

| Area | Points |
|---|---:|
| Evidence provenance and reproducibility | 20 |
| Correct event interpretation | 20 |
| Correlation and alternative hypotheses | 20 |
| Clear severity/confidence rationale | 20 |
| Proportionate, authorized recommendations | 20 |

Passing requires no unsupported attribution, no unsafe testing, and explicit discussion of evidence gaps.
