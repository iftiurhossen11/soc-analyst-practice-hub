# Lab 1 — End-to-End Investigation

**Module:** 8 · **Level:** intermediate · **Estimated time:** 3–4 hours

Combine the synthetic Windows, network, email, and detection-engineering evidence into one reproducible investigation. There is no confirmed incident.

## Evidence set

- Module 1: Windows Security event analysis
- Module 3: Network connection review
- Module 4: Static email triage
- Module 6: Local account detection test
- [`data/case-manifest.md`](data/case-manifest.md)

## Deliverables

1. One-page executive summary.
2. UTC timeline with sources and confidence.
3. Reproducible queries or analysis steps.
4. Findings table with alternatives and evidence gaps.
5. Owner-approved containment recommendation.
6. One detection improvement and lessons learned.
