# Lab 1 — IOC Context Worksheet

**Module:** 7 · **Level:** beginner to intermediate · **Estimated time:** 1–2 hours

Assess fictional observables without querying public reputation services. All values use reserved examples or placeholders.

## Contents

- [`data/ioc-worksheet.csv`](data/ioc-worksheet.csv)
- [`REPORT-TEMPLATE.md`](REPORT-TEMPLATE.md)

## Tasks

1. Classify each observable and record its source and expiration.
2. Explain why a match is not proof of malicious activity.
3. List benign reasons for a match.
4. Define the confidence and sharing checks required for a real authorized case.
